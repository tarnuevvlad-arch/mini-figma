Скачать ZIP для Windows и macOS Открыть в браузере

Что даёт локальная версия

Шрифты с компьютера: интерфейс рисует системный шрифт — Segoe UI на Windows, SF на macOS, никакого ожидания загрузки
Работа без сети: после установки зависимостей интернет не нужен вовсе
Несколько окон: откройте два окна браузера — редактор работает в каждом независимо

Как запустить (3 шага)

  1. Распакуйте ZIP в любую папку
  2. Установите Node.js один раз — nodejs.org
  3. Двойной клик по файлу start.cmd — зависимости поставятся сами, редактор откроется на localhost:5173
